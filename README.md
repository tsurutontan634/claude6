# しあわせ配分帳

「ずっと働くのも、ずっと遊ぶのも違う」。あなたにとってちょうどいい時間とお金の配分を、経済学の **効用最大化** で計算する日本語の Web アプリです。

- 研究データ（収入と満足度、活動ごとの楽しさ、睡眠・運動の最適量、通勤、家族・仕事・引退の研究、日本の生活時間・賃金・税・年金・生命表）から「平均的な人の効用関数」を作り、
- 「A と B、どちらの1週間が幸せ？」という 1対1 の質問への回答で、**あなた専用の効用関数** にベイズ更新し、
- **最適な1週間**（睡眠・友人・家族・趣味・休息・運動・学び）、**労働時間**、**お金の使い道**、**年ごとの人生計画**（昇給・結婚/子育て・教育費・年金・貯蓄・引退）を提案します。

参考・エンターテインメント用の試算です。医療・金融・キャリアの専門的な助言の代わりにはなりません。

## しくみ（概要）

| 段階 | 方法 |
| --- | --- |
| 効用関数 | 活動ごとに逓減する効用 `w·S·(1−e^(−h/S))`、消費は等価消費の CRRA、支出の使い道の上乗せ、貯金の安心感、仕事の楽しさ・長時間労働・所属感、通勤。単位は「0〜10点の人生満足度」 |
| 事前分布 | 文献から 25 個のパラメータの分布を作成（`src/engine/priors.ts`、根拠は `docs/MODEL.md`） |
| 回答モデル | 5段階の順序ロジット（押し間違い 4%）。想像の中の選択は経験とずれるため尤度を 0.7 乗 |
| 推定 | 2,000 粒子の逐次モンテカルロ（リサンプリング＋メトロポリス・ヘイスティングス移動） |
| 質問の選び方 | 10 種類のひな形から候補を作り、期待情報利得が最大の質問を出題。A/B の左右はランダム、確認問題と再質問を混ぜる |
| 1週間の最適化 | 限界効用が均等になるまで 15 分ずつ配分（貪欲法、凹関数なので最適） |
| 人生計画 | 年ごとに手取り・年金・教育費・育児時間を計算し、消費と貯蓄を動的計画法で最適化。労働時間と引退年齢は探索 |

架空のユーザー（真の好みを決めて質問に答えさせる）で検証すると、100問の回答で「提案の損失」が回答ゼロのときより 75〜97% 減りました（`docs/MODEL.md`）。

## 使い方

```bash
npm install
npm run dev          # 開発サーバー
npm test             # エンジンのテスト
npm run build        # dist/ に通常のビルド
npm run build:single # dist-single/index.html に1ファイルにまとめたビルド（オフラインで開ける）
```

回答とプロフィールはブラウザの `localStorage` にだけ保存され、外部には送信しません。「データ管理」から JSON で書き出し・読み込みができます。

## ディレクトリ

```
src/engine/   計算エンジン（UI に依存しない TypeScript）
  model.ts      効用関数とパラメータの並び
  priors.ts     事前分布（研究データ）
  sources.ts    出典
  choice.ts     順序ロジットの回答モデル
  posterior.ts  粒子によるベイズ推定
  design.ts     期待情報利得による質問選択
  questions.ts  質問のひな形と日本語の文面
  week.ts       1週間の最適配分
  kit.ts        期待効用の早見表（高速化）
  household.ts  プロフィール → 今の生活、収入・通勤・世帯
  tax.ts        手取り・年金の概算（2026年度の料率）
  data.ts       賃金カーブ・育児時間・教育費・児童手当・生存率
  lifeplan.ts   年単位の人生計画シミュレーション
  insights.ts   円換算・タイプ判定・お金の満足度カーブ
  session.ts    エンジンの窓口
src/ui/       React の画面
docs/MODEL.md モデルの詳細・校正の根拠・検証・限界
```
